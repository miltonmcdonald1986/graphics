Detailed Description

Core diagnostics, logging, and error-handling subsystem.

The graphics::core namespace provides the foundational error-reporting and diagnostic facilities used throughout the engine. This includes diagnostic message representation, subsystem categorization, log levels, logging interfaces, and lightweight error/expected-value utilities.

Responsibilities

Diagnostics

  • Diagnostic message structure (Diagnostic)
  • Source-location-aware error reporting
  • Diagnostic categories (DiagnosticCategory)
  • Severity levels (LogLevel)

These components provide a unified mechanism for describing and reporting errors, warnings, and informational messages across all engine subsystems.

Logging

  • Logging interface and helpers (logging.hpp)
  • Integration with diagnostic messages

Logging is built on top of the diagnostic system and provides a consistent way to emit structured messages during engine execution.

Error and Status Handling

  • Status codes (status.hpp)
  • Expected-value type (expected.hpp)

These utilities support expressive and lightweight error propagation without relying on exceptions, enabling predictable control flow and efficient error handling.

Notes

  • All engine subsystems should use these facilities for reporting errors and diagnostics.
  • Higher-level modules (rendering, math, platform) depend on this layer.
  • This namespace forms the foundation of the engine's reliability model.
