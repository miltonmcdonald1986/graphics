Detailed Description

Root namespace for the graphics engine.

Contains all engine subsystems, including:

  • graphics::core (diagnostics, logging, error handling)
  • graphics::platform (platform abstraction and backend selection)

This namespace itself does not contain code directly; it serves as the top-level grouping for all engine modules.
