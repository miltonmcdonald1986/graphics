Detailed Description

Platform abstraction layer of the graphics engine.

The graphics::platform namespace defines the interfaces and backend selection mechanisms used to interact with the underlying operating system and windowing environment. This layer isolates platform-specific behavior behind a clean, engine-facing API.

Responsibilities

Platform Interface

  • i_platform — abstract interface representing the platform backend

The platform interface defines the minimal set of operations required by the engine, such as initialization, shutdown, window creation, and event polling. All platform backends must implement this interface.

Backend Selection

  • backend.hpp — backend enumeration and selection helpers

This component provides the mechanism for choosing which platform implementation to use (e.g., GLFW, Win32, SDL). It allows the engine to remain backend-agnostic while supporting multiple windowing systems.

Design Goals

  • Provide a stable, minimal API for platform interaction
  • Allow multiple backend implementations without changing engine code
  • Keep platform-specific details isolated from higher-level systems

Notes

  • All platform backends must implement i_platform.
  • Backend selection is performed through the facilities in backend.hpp.
  • Higher-level systems (rendering, diagnostics, input) depend on this namespace for window creation and event dispatch.
